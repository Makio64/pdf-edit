# PDF Edit

I made PDF Edit to help my mum edit her PDFs on her Mac, and for anyone who needs a fast and easy way to edit a PDF.

- **Correct a few words** right in the PDF: same font, nothing else on the page moves.
- **Or turn it into a Word or Pages document** to rework it.

Free, no account, no ads, and your documents never leave your computer. The app speaks French for now.

**[Download for Mac](https://github.com/Makio64/pdf-edit/releases/latest)** (macOS 11 or later) · **[Use it online](https://pdf-edit-mac.netlify.app/en-ligne/)** · [Website](https://pdf-edit-mac.netlify.app)

## For developers

Rust, compiled for the Mac and to WebAssembly for the browser.

```bash
pnpm test
```

```bash
pnpm app
```
