Questions fréquentes

Ce que l’on se demande souvent avant d’installer PDF Edit.

PDF Edit est-il vraiment gratuit ?

Oui. Vous pouvez modifier un PDF gratuitement et sans inscription : l’application Mac et la version en ligne sont gratuites, sans publicité et sans abonnement.

Mes documents sont-ils envoyés sur Internet ?

Non. Vos PDF sont lus et transformés sur votre ordinateur, jamais envoyés. Seule exception : s’il manque une police gratuite, l’application la télécharge une fois depuis Google Fonts ; seul le nom de la police est demandé, jamais le document.

Faut-il avoir Word ou Pages ?

Pour corriger quelques mots directement dans le PDF, non : rien d’autre n’est nécessaire. Pour « Modifier dans Pages », l’app Pages d’Apple doit être installée sur le Mac. Le fichier Word (.docx) s’ouvre dans Word, mais aussi dans Pages.

Quelle version de macOS faut-il ?

macOS 11 Big Sur ou plus récent, sur un Mac avec processeur Intel comme sur un Mac Apple Silicon (puces M1 et suivantes).

Et sur Windows ou Linux ?

L’application est réservée au Mac, mais la version en ligne fonctionne aussi sur Windows et Linux, dans un navigateur récent (Chrome, Edge ou Firefox). Elle donne un fichier Word (.docx).

Mon PDF est protégé par un mot de passe : est-ce possible ?

Oui, pour le transformer en Word ou en Pages : PDF Edit vous demande le mot de passe, qui reste sur votre ordinateur. En revanche, un PDF protégé ne peut pas encore être corrigé directement.

Mon PDF d’origine est-il modifié ?

Non. PDF Edit crée toujours un nouveau fichier, à l’endroit que vous choisissez : sur le Bureau, dans Téléchargements ou dans un autre dossier. Votre PDF d’origine reste tel quel, et aucun fichier existant n’est remplacé.

Comment désinstaller PDF Edit ?

Ouvrez le dossier Applications et glissez PDF Edit (anciennement « Modifier mes PDF ») dans la Corbeille. Les polices gratuites éventuellement ajoutées restent sur le Mac ; vous pouvez les retirer avec l’app Livre des polices.
